<p><strong>Edusave – Standing Order</strong>
</p>
<p>Parents/Guardians of Singapore Citizen (SC) students can use their child’s/ward’s
Edusave funds to pay for approved fees and enrichment programme fees to
reduce their cash out-of-pocket expenses.</p>
<p>With effect from 27 July 2026, parents/guardians can access the new MOE’s<strong> Student Finance System (SFS)</strong> using
Singpass to set up <strong>a one-time Edusave Standing Order (SO</strong>)
to authorise the school to withdraw funds from their child’s/ward’s Edusave
account to pay for enrichment programmes once parental consent for participation
has been obtained</p>
<p>After the Edusave SO has been set up, there is no need for parents/guardians
to repeat the process for future approved programmes. The SO will remain
in effect until it is terminated by the parent/guardian.</p>
<p>&nbsp;</p>
<p><strong>How to Set Up the Standing Order</strong>
</p>
<ol data-tight="true" class="tight">
<li>
<p>Log in to the Student Finance System at <a href="https://studentfinance.moe.gov.sg" rel="noopener noreferrer nofollow" target="_blank">https://studentfinance.moe.gov.sg</a> using
either Parent’s/Guardian’s Singpass.</p>
</li>
<li>
<p>Alternatively, scan the QR code below for quick access to the system.</p>
</li>
<li>
<p>Follow the on-screen instructions to complete the Standing Order setup.</p>
</li>
</ol>
